# Talk-T-Stop-Alarm
it is a website for Those who need alarm
📢 Talk-to-Dismiss Alarm App
A modern, interactive alarm clock that forces you to wake up your brain—not just your body. Instead of simply tapping a snooze button, this app requires you to speak continuously for 60 seconds about a randomly generated topic to dismiss the alarm.

🚀 Core Idea
The alarm rings at your chosen time and won’t stop until you actively engage by speaking. Using the Web Speech API, the app listens to your voice, tracks actual speaking duration, and only dismisses the alarm once you complete the full challenge.

✨ Features


⏰ Alarm Setter
Set a one-time alarm with a clean and minimal time picker interface.


🔔 Alarm Trigger
Plays a looping alarm sound and launches a challenge screen when time is reached.


🎯 Challenge Screen
Displays a random speaking topic to keep the experience fresh and engaging.


🎙️ Speech Detection (Web Speech API)
Detects real-time speech and tracks actual talking time (pauses when you stop speaking).


📊 Progress Indicator
Animated progress bar/ring showing how close you are to completing the 60-second speaking goal.


✅ Smart Dismiss Logic
Alarm stops only after successfully completing the speaking challenge.


😴 Snooze Option (Optional)
Delay the alarm by 5 minutes if needed.



🛠️ Tech Stack


Frontend: React (Functional Components + Hooks)


Styling: CSS (custom dark theme, no UI libraries)


APIs Used:


Web Speech API (SpeechRecognition)


Web Audio API / HTML <audio>




Architecture: Fully client-side (no backend)



🎨 Design


Dark, minimal alarm-clock inspired UI


Bold typography for clarity and focus


Glowing mic button with animated progress ring


Smooth transitions and interactive feedback

This app solves a real problem—habitual snoozing—by forcing cognitive engagement. It blends frontend engineering, browser APIs, and UX design into a unique productivity tool.
